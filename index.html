About Me

Profil Singkat

Saya Syahdan Ramadhan, seorang siswa SMK jurusan Rekayasa Perangkat Lunak (RPL) yang memiliki minat dalam dunia teknologi, sistem operasi Linux, dan open source. Saya senang mempelajari hal-hal baru serta terus mengembangkan kemampuan melalui pembelajaran di sekolah dan proyek pribadi. Saat ini saya masih berada dalam tahap belajar dan berusaha meningkatkan keterampilan saya di bidang teknologi informasi.

Keahlian

Saya memiliki kemampuan dasar dalam menggunakan sistem operasi Linux, khususnya Ubuntu, Debian, Kubuntu, dan Arch Linux. Selain itu, saya juga memiliki pengalaman dasar menggunakan Git dan GitHub untuk mengelola kode program, Docker untuk menjalankan lingkungan pengembangan berbasis container, serta MySQL untuk mengelola database. Saat ini saya terus mempelajari berbagai teknologi dan berusaha meningkatkan kemampuan melalui praktik, tugas sekolah, dan proyek pribadi.

My Projects

Linux Environment & System Configuration

Mempelajari dan menggunakan berbagai distribusi Linux seperti Ubuntu, Debian, Kubuntu, dan Arch Linux. Memiliki pengalaman dalam instalasi sistem operasi, penggunaan terminal, manajemen paket, serta konfigurasi dasar untuk mendukung kebutuhan pembelajaran dan pengembangan. Teknologi: Linux, Bash.

MySQL Database

Membuat dan mengelola database menggunakan MySQL, mulai dari pembuatan database dan tabel hingga melakukan operasi dasar seperti menambah, menampilkan, mengubah, dan menghapus data. Proyek ini membantu memahami konsep dasar pengelolaan database dan relasi antar tabel. Teknologi: MySQL.

CRUD Application

Mengembangkan aplikasi CRUD (Create, Read, Update, Delete) sederhana berbasis web untuk mengelola data. Proyek ini dibuat sebagai media pembelajaran untuk memahami alur pengolahan data, koneksi database, serta operasi dasar dalam aplikasi berbasis PHP dan MySQL. Teknologi: PHP, MySQL.
